# Flight Route Optimization System

A Java-based project that finds the shortest-distance route between airports using graph algorithms.

## Features
- Graph representation using an adjacency list
- Dijkstra's shortest-path algorithm
- PriorityQueue-based traversal
- Displays airports and flight routes
- Calculates shortest distance and route
- Handles invalid airport codes

## Technologies
- Java
- Graphs and adjacency lists
- Dijkstra's Algorithm
- PriorityQueue
- Java Collections Framework

## Algorithm
Dijkstra's algorithm finds the minimum-distance route between two airports using non-negative edge weights.

## Complexity
- Time: O((V + E) log V)
- Space: O(V + E)

## How to Run

Compile:
```bash
javac FlightRouteOptimization.javav# Flight Route Optimization System
